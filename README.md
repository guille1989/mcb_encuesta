# MCB Encuesta

Encuesta de lanzamiento de The Mother Coffee Baby, construida con Next.js 16, React 19, TypeScript y Tailwind CSS 4.

## Desarrollo

```bash
npm install
npm run dev
```

Las respuestas se guardan en el almacenamiento local del navegador bajo la clave `mcb-survey-responses`. El progreso sin enviar se conserva en `mcb-survey-draft`.
